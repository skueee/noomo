# The frontent of Noomo !
**Built in typescript, using NextJS, TailwindCSS and pnpm**

---

### Running

**Dependencies :**
- PNPM
- Node

**1. Clone the repo**
```
git clone https://github.com/skueee/noomo
```
**2. Go to the frontend directory**
```
cd noomo/frontend/noomo-frontend
```
**3. Install dependencies**
```
pnpm install
```
**4. Launch the server**
```
pnpm run dev
```

> [!NOTE]
> If you want to change the API URL (if you run the API locally), you should change it in `./frontend/noomo-frontend/src/app/actions.tsx`.

---

### Developing

**Linting and formating**

Please execute these commands before your pr :

```
pnpm run lint
```
and
```
pnpm run format
```
