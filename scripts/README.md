# Scripts

This is were utilities for dev are stored

## Running

UV is not used there.

To execute most projects, just create a venv with
```
python -m venv .venv
```
then go to the folder with the script and execute
```
pip install -r requirements.txt
```
Now you can run the script !

If you know about Python, this should be very familiar to you. If you do not knew about this, it would be better to learn about Virtual Environments first.

## Developping

1. Create a folder
2. Create a requirements.txt
3. Develop !

Please try to use Python for your scripts as mush as you can.

If you do not use Python, please write a README with how to run and to develop for your script (even if a README is also nice to have for Python scripts)
