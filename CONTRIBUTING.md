# Noomo
Thanks for your interest in Noomo ! Here is some guidelines and advices to help you contribute to the project.

## Opening issues
If you encounter a bug or would like to see a new feature, you can open an issue !
Please make clear issues in English. If it is a bug, please provide reproductible steps and what the game should do instead.
Issue templates are coming soon :)

## Developing
### Structure
This repository is structured with two main directories :
**Backend :** The backend of the game, a FastAPI project using UV.
**Frontend :** The frontend of the game, what you will see, made in HTML, JS and CSS.
**For dev instructions, please check the CONTRIBUTING.md in the Backend and Frontent folders**
